Integrations & logic

Custom billing · quote-first — form submit charges $0 and creates a quote-request record → artist approves preview → Stripe Invoicing collects a 50% deposit, then the balance before shipping. Never charge full price at submit.
Fulfillment — completed order → append a PirateShip export row (name, address, weight). No native API — batch CSV or Zapier bridge. Per-SKU weight mandatory.
Inventory — decrement on purchase; 0 → sold out. Limited editions are stock-of-one and edition-numbered.
Email — transactional (order confirm, custom-received, invoice) + capture ("Notify me" / newsletter). Build a portable capture; provider chosen & wired before launch.
CMS authoring — a product publishes with photos + description + price + weight only — no layout editing by the artist.
Definition of done
All six routes live & responsive; one global nav.
CMS model matches spec; artist publishes with no layout work.
Checkout charges via Stripe; every policy box enforced.

Orders export to PirateShip with correct weights.
